このページ、実はAIで全部つくれます

石島の1to1シートは、文章もデザインもイラストも動画も、AIと一緒につくりました。
作り方をまとめておきます。

つくり方 7ステップ

  1. 1.

    材料を集める

    1to1やウィークリープレゼンの文字起こし、今の1to1シート、お客様の声を集めます。
    AIは、材料が多いほど「その人らしい」文章を書けます！

  2. 2.

    構成をAIと考える

    BNIの公式ブログやポッドキャストの内容を読ませて、「紹介が生まれる1to1シートにするには？」を相談します。
    どこを残して、どこを削るかも一緒に決めます。

  3. 3.

    文章を自分の言葉に直す

    AIの下書きを、自分の言葉に直します。
    語尾や言い回しを自分らしくするのが一番大事です！

  4. 4.

    デザインはAIに任せる

    「文字を太く」「画像を増やして楽しく」のように、感想を伝えるだけで作り直してくれます。

  5. 5.

    イラストもAIで描く

    このページのアイコンは、すべてAIで描きました。

  6. 6.

    使い方の動画もAIでつくる

    画面のキャプチャーと、AIで再現した自分の声で、46秒の動画にしました。

  7. 7.

    無料で公開する

    GitHub Pages という無料の仕組みで公開しています。
    URLひとつで、誰にでも渡せます。

使った道具

  • Claude Code：構成・文章・ページづくり
  • Codex CLI：デザイン・イラスト
  • Gemini：声の読み上げ
  • GitHub Pages：公開（無料）
